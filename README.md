# PartageCompetenceCodeIgniter
Plateforme collaborative de partage de compétences

# Règle de gestion 
RG1 : Un utilisateur peut publier plusieurs publication
RG2 : Une publication est rattaché à un seul utilisateur
RG3 : Une publication peut avoir plusieurs commentaires et on peut répondre à ces commentaires
RG4 : Un utilisateur peut liker plusieurs publication qu'une seul fois.
RG5 : Après un like ou une commentaire, l'utilisateur propriétaire de la publication reçevera une notification

# Base de données utiliser
PostgreSQL : sharing_db

# Technologie
CodeIgniter : backend
React : frontend
